# 영상/자막 맞춤법 검사기

영상(또는 음성) 파일을 올리면 자동으로 한국어 음성을 텍스트로 바꾸고(STT),
자막 파일(.srt/.vtt)이나 텍스트(.txt)를 올리면 바로, 한국어 맞춤법·띄어쓰기를
검사해서 보여주는 간단한 웹 앱입니다.

## 할 수 있는 것

- 영상/음성 파일(mp4, mov, mkv, mp3, wav 등) → 자동 자막 추출 → 맞춤법 검사
- 자막 파일(srt, vtt) → 바로 맞춤법 검사
- 텍스트 파일(txt) → 바로 맞춤법 검사
- 결과를 구간별로 원문/교정본 비교해서 보여줌
- 검사 리포트(.txt) 다운로드, 교정된 자막(.srt) 다운로드
- **러프 컷(컷편집)**: 무음 구간, "음·어" 같은 군더더기, 같은 말을 다시 한 NG 테이크를
  잘라낸 편집본을 프리미어 프로용 XML로 다운로드 (잘린 길이에 맞춘 자막 .srt도 같이)

## 프리미어 프로와 함께 쓰는 법

### 1) 맞춤법만 확인하기

1. 프리미어 프로 **텍스트** 패널 → **캡션** 탭에서 자막을 만든 뒤(또는 이미 만든 자막에서)
   `…` 메뉴 → **SRT 파일로 내보내기**
2. 이 앱에 `.srt` 파일을 올리면 구간별로 원문/교정본을 보여줌
3. **수정된 자막 (.srt) 다운로드** → 프리미어에서 **파일 > 가져오기**로 불러와 기존 캡션 대신 사용

### 2) 영상이 너무 길 때: 러프 컷 맡기기

1. 원본 영상 파일을 그대로 올림 (파일이 너무 크면 아래 팁 참고)
2. 맞춤법 검사 결과 아래 **✂️ 러프 컷 → 프리미어 프로** 에서
   - 무음 기준(초), 앞뒤 여유(초), NG 테이크/군더더기 빼기 여부를 정하고
   - **원본 영상 파일 경로**에 내 컴퓨터에서의 전체 경로를 넣음
     (윈도우: 파일 Shift+우클릭 → "경로로 복사", 맥: Option+우클릭 → "경로 이름 복사")
   - 표에서 구간별로 "사용"을 켜고 끄며 확인
3. **프리미어용 XML**과 **러프 컷에 맞춘 자막(.srt)** 을 다운로드
4. 프리미어 프로: **파일 > 가져오기**로 XML을 열면 컷편집된 새 시퀀스가 생김.
   클립이 오프라인(빨간 화면)이면 우클릭 → **미디어 연결**로 원본 선택.
   자막 .srt도 가져와서 시퀀스 0초 위치에 놓으면 잘린 영상과 타이밍이 맞음

원본 클립은 건드리지 않고 새 시퀀스만 생기므로, 마음에 안 들면 지우고 설정을 바꿔 다시 받으면 됩니다.

**팁 — 영상 파일이 너무 클 때**: 프리미어 프로젝트 패널에서 원본 클립을 골라
**파일 > 내보내기 > 미디어**로 오디오만(MP3) 내보내서 올려도 됩니다. 이때 클립 앞부분을
자르지 말고 처음부터 끝까지 내보내야 컷 위치가 맞고, 러프 컷 화면에서 원본 영상의
경로·프레임 속도·해상도를 직접 맞춰줘야 합니다 (원본 클립 우클릭 → **속성**에서 확인).

**한계**: 판단은 규칙 기반이라 완벽하지 않습니다. 말소리가 없는 구간(B-roll, 음악만 나오는
부분 등)은 무음으로 보고 잘라내니, 그런 부분은 프리미어에서 다시 살려주세요. 자막 파일만
올려서 러프 컷을 만들면 자막 타이밍 기준이라 영상/음성 파일보다 덜 정확합니다.

## 파일 구성

- `app.py` — 웹 화면(Streamlit)
- `srt_io.py` — 자막(srt/vtt) 파싱 및 생성
- `spellcheck.py` — 네이버 맞춤법 검사 호출
- `transcribe.py` — 영상/음성 → 자막 텍스트 변환(STT, faster-whisper, 단어별 타임코드 포함)
- `roughcut.py` — 러프 컷 판단(무음·군더더기·NG 테이크) 및 잘린 타임라인용 자막 계산
- `premiere_xml.py` — 프리미어 프로에서 가져올 수 있는 XML(Final Cut Pro 7 XML) 생성
- `requirements.txt`, `packages.txt` — 필요한 패키지 목록
