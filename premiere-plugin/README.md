# 프리미어 프로 플러그인: 자막 맞춤법 · AI 컨펌

프리미어 프로 안에서 패널로 열어 쓰는 플러그인입니다.

- **맞춤법**: 자막(SRT·VTT·TXT 파일, 또는 타임라인의 그래픽 텍스트)을 Claude나 네이버 맞춤법 검사기로 검사합니다. 바뀐 글자를 색으로 보여 주고, 시간을 누르면 그 위치로 재생헤드가 이동합니다. 수정할 곳을 타임라인 마커로 찍고, 교정된 SRT로 저장할 수 있습니다.
- **검수팀 리뷰 (AI 컨펌)**: 시퀀스에서 정지 화면(프레임)을 뽑아 '밤샘 콘텐츠 컴퍼니' 검수팀에게 보냅니다. 검수팀이 주관하고 카피라이팅·디자인·영상제작·브랜딩팀이 함께 봐서 "몇 분 몇 초에 자막 느낌·멘트·디자인을 이렇게 바꾸면 좋겠다"는 의견을 다른 느낌의 대안과 함께 줍니다. 오타·가독성 같은 꼭 고칠 오류도 짚고, **컨펌 / 수정 후 컨펌 / 재작업 필요** 판정을 냅니다. 의견은 타임라인 마커(빨강=필수, 주황=권장, 파랑=참고)로 찍을 수 있습니다.

## Claude를 쓰는 두 가지 방식

| | 내 Claude 구독 (기본, 권장) | API 키 |
| --- | --- | --- |
| 비용 | 추가 비용 없음. 구독(Pro·Max) 사용량에서 차감 | 쓴 만큼 따로 과금 |
| 준비 | PC에 Claude Code 설치·로그인 + 구독 연결 프로그램 켜 두기 | [console.anthropic.com](https://console.anthropic.com)에서 키 발급 |
| 지원 | Windows | Windows·Mac |

구독 방식은 플러그인이 이 PC의 **구독 연결 프로그램**(`claude-bridge.ps1`)에 작업을 넘기고, 그 프로그램이 PC에 로그인된 **Claude Code**(`claude -p`)로 검사합니다. 무료 claude.ai 요금제에는 Claude Code가 없어서 Pro 이상이 필요합니다. 프레임이 많으면 구독 사용량을 꽤 쓰니, 한도에 자주 걸리면 설정에서 모델을 Sonnet으로 바꾸거나 프레임 수를 줄이세요.

네이버 엔진으로 맞춤법만 검사할 때는 둘 다 없어도 됩니다.

## 준비물

- **Premiere Pro 25.6 이상** (UXP 플러그인을 지원하는 버전). 도움말 > Premiere Pro 정보에서 버전을 확인하세요.
- 구독 방식: **Claude Pro 이상 구독**과 Windows 10 이상.
- API 방식: **Anthropic API 키**.

## 설치

### 1단계: 플러그인 설치 (.ccx 더블클릭)

1. 이 저장소의 [`premiere-plugin/dist/subtitle-checker-premiere-1.3.2-windows.zip`](dist/subtitle-checker-premiere-1.3.2-windows.zip)을 내려받아 압축을 풉니다 (GitHub에서 파일을 열고 Download raw file). 안에 `.ccx`, `claude-bridge.ps1`, `README.txt`가 있습니다. Mac은 [`.ccx`](dist/subtitle-checker-premiere-1.3.2.ccx)만 받으면 됩니다.
2. 프리미어를 끈 상태에서 `.ccx` 파일을 더블클릭합니다. Creative Cloud 데스크톱 앱이 설치를 진행합니다. 마켓플레이스 밖에서 받은 플러그인이라는 확인 창이 나오면 설치를 계속하세요.
3. 프리미어를 켜고 **창(Window) > UXP 플러그인(UXP Plugins) > 자막 맞춤법 · AI 컨펌**을 엽니다.

더블클릭이 안 될 때는 아래 명령어로 설치하거나, 개발자 모드로 불러오세요.

#### 명령어로 설치

Windows (PowerShell):

```powershell
& "C:\Program Files\Common Files\Adobe\Adobe Desktop Common\RemoteComponents\UPI\UnifiedPluginInstallerAgent\UnifiedPluginInstallerAgent.exe" /install "$env:USERPROFILE\Downloads\subtitle-checker-premiere-1.3.2.ccx"
```

macOS (터미널):

```bash
"/Library/Application Support/Adobe/Adobe Desktop Common/RemoteComponents/UPI/UnifiedPluginInstallerAgent/UnifiedPluginInstallerAgent.app/Contents/MacOS/UnifiedPluginInstallerAgent" --install ~/Downloads/subtitle-checker-premiere-1.3.2.ccx
```

#### 개발자 모드 (UXP Developer Tool)

1. 프리미어 **설정(Settings) > 플러그인(Plugins) > 개발자 모드 사용(Enable developer mode)**을 켜고 프리미어를 다시 시작합니다.
2. Creative Cloud 앱에서 **UXP Developer Tool**을 설치해 엽니다.
3. **Add Plugin** → `premiere-plugin/plugin/manifest.json` 선택 → **Load**.

이 방법은 프리미어를 다시 켤 때마다 Load를 다시 눌러야 할 수 있어요. 코드를 고치면서 쓸 때 편합니다.

### 2단계: 내 Claude 구독 연결 (구독 방식만)

1. **Claude Code 설치** (처음 한 번): 시작 메뉴에서 PowerShell을 열고 아래를 붙여넣습니다. 관리자 권한은 필요 없어요.

   ```powershell
   irm https://claude.ai/install.ps1 | iex
   ```

   새 PowerShell 창에서 `claude`를 실행하고, 브라우저가 열리면 내 Claude 계정(Pro·Max)으로 로그인합니다. 로그인이 끝나면 그 창은 닫아도 됩니다.
2. **구독 연결 프로그램 켜기** (프리미어를 쓸 때마다): 압축을 푼 폴더의 `claude-bridge.ps1`을 마우스 오른쪽 버튼으로 누르고 **PowerShell에서 실행**을 고릅니다. 윈도우 11은 오른쪽 버튼 메뉴에서 **추가 옵션 표시**를 누르면 나와요. 보안 경고가 나오면 한 번 실행(R)을 고르세요. 파란 창에 "Claude 로그인: 됨"과 "준비 완료"가 뜨면 프리미어를 쓰는 동안 그 창을 켜 둡니다.
   - 창에 "Claude 로그인: 안 됨"이 나오면 1번의 로그인을 다시 하고 창을 다시 엽니다.
   - 오류가 나면 창이 바로 닫히지 않고 빨간 글씨로 이유를 보여 줍니다.
3. 프리미어 패널 **설정** 탭에서 사용 방식이 **내 Claude 구독**인지 확인하고 **구독 연결 확인**을 누릅니다. 연결 프로그램 → Claude Code → 로그인 → 실제 응답을 차례로 확인해서 ✅/❌와 해결 방법을 보여 줘요. 요금제에서 Opus를 쓸 수 없으면 Sonnet으로 바꿔서 연결해요.

구독 연결 프로그램은 이 PC 안(127.0.0.1, 포트 41234부터 빈 곳)에서만 연결을 받고, 플러그인이 보낸 작업만 처리합니다. Claude Code는 작업 폴더 안 파일을 읽는 도구만 쓰도록 제한해서 실행합니다. 작업이 끝나면 임시 폴더를 지웁니다.

## 사용법

### API 방식으로 쓸 때: API 키 넣기

설정 탭 → 사용 방식 **API 키** → 키 붙여넣기 → **저장** → **연결 테스트**. 키는 이 컴퓨터의 보안 저장소에만 저장됩니다.

### 맞춤법 검사

1. **자막 불러오기**
   - 프리미어 캡션 자막: 텍스트 패널(창 > 텍스트)의 캡션 탭 ··· 메뉴에서 **SRT 파일로 내보내기**를 한 뒤, 패널에서 **자막 파일 열기**.
   - Vrew 같은 다른 프로그램에서 만든 SRT도 그대로 열 수 있어요. 파일은 UTF-8이어야 합니다.
   - 문자 도구나 MOGRT로 넣은 그래픽 자막 (텍스트 패널의 그래픽 탭에 보이는 글자): **타임라인 그래픽 텍스트 읽기**.
     - 프리미어 25.6~26.x는 플러그인에 그래픽 글자 값을 알려 주지 않는 경우가 많아요 (Adobe에 알려진 문제). 그래서 효과 컨트롤에 보이는 레이어 이름 "텍스트(…)"나 클립 이름에서 읽고, 그래도 못 읽은 클립은 **구독 방식이면 바로 화면을 보고 받아 적습니다** (추가 비용 없음).
     - **화면 보고 받아 적기 (Claude)**: 그래픽 클립마다 프레임을 한 장씩 뽑아 Claude가 화면 글자를 틀린 글자까지 그대로 받아 적어요. 이름에서 읽은 글자는 고친 뒤 이름이 안 바뀌었으면 실제 화면과 다를 수 있으니, 정확하게 검사하려면 이 버튼을 쓰세요. 영상 내내 떠 있는 코너 제목처럼 겹친 그래픽은 클립별로 나눠 줍니다.
     - 결과 카드에 `레이어 이름`·`클립 이름`·`화면` 표시가 붙어서 어디서 읽은 글자인지 알 수 있어요.
2. 검사 엔진을 고르고 **맞춤법 검사 시작**.
   - Claude: 문맥까지 보고 고치고, 이유를 알려 줍니다. 구독 방식이면 내 구독 사용량에서 차감되고 추가 비용이 없어요. API 방식은 쓴 만큼 과금돼요.
   - 네이버: 무료지만 네이버 쪽 사정으로 막힐 수 있어요.
3. 결과 보기: 빨간 취소선은 지울 글자, 초록은 새 글자, `␣`는 띄어쓰기입니다. 시간 버튼을 누르면 재생헤드가 그 자막으로 갑니다. 원하지 않는 제안은 **이 제안 빼기**.
4. **타임라인에 마커로 표시**: 수정할 자막마다 노란 마커가 생깁니다 (확인이 필요한 곳은 파란 마커). 마커 패널에서 하나씩 넘겨 보며 고치면 됩니다.
5. **교정된 자막 저장**: 저장한 SRT를 프로젝트로 가져와(Ctrl/Cmd+I) 타임라인에 끌어다 놓으면 캡션 트랙으로 들어갑니다. 그래픽 자막은 마커를 보며 직접 고쳐 주세요.

### 검수팀 리뷰

1. 처음 한 번: **설정** 탭의 **우리 채널 정보**에 채널 소개·타깃·톤앤매너를 적습니다 (밤샘 콘텐츠 컴퍼니 설정에 적은 내용을 옮기면 돼요). 검수팀이 이 기준으로 제안합니다.
2. 멘트까지 보려면 **맞춤법** 탭에서 자막(SRT)을 먼저 불러옵니다. 자막이 곧 멘트로 쓰여요.
3. 검토할 시퀀스를 엽니다. 일부만 볼 때는 인/아웃 점을 찍고 **검토 구간**을 '인·아웃 구간만'으로 고릅니다.
4. **검수팀 리뷰** 탭에서 프레임 간격, 최대 프레임 수, 검토 초점, 요청사항(예: "이번 편은 더 웃기게, 로고는 오른쪽 위에 계속")을 정합니다.
   - 전체 리뷰: 꼭 고칠 오류 + 더 좋게 만드는 제안
   - 오류 위주: 맞춤법·오타·가독성
   - 제안 위주: 자막 느낌·멘트·디자인·편집 호흡
5. **검수팀에 리뷰 요청** → 프레임을 뽑아 보내고 검수팀이 봅니다 (API 방식은 보통 1~3분, 구독 방식은 2~5분).
6. 판정과 총평, 그리고 시간순 의견이 나옵니다. 의견마다 담당 팀(검수팀·카피라이팅팀·디자인팀·영상제작팀·브랜딩팀), 지금 상태, 추천 수정안, 다른 느낌의 대안, 그 시점의 화면이 붙어요. 시간을 누르면 그 위치로 이동합니다.
7. **타임라인에 마커로 표시**하면 빨강(필수)·주황(권장)·파랑(참고) 마커가 생기고, 마커 설명에 제안과 대안이 들어갑니다. **AI 마커 모두 지우기**는 이 플러그인이 만든 마커만 지웁니다.

팁: **불러온 자막마다 한 장씩** 옵션을 켜면 자막이 바뀔 때마다 한 장씩 보내서, 자막마다 의견을 받기 좋아요.

### 잘 안 될 때

- 패널 제목 옆에 설치된 버전(예: v1.3.2)이 보입니다. 새 버전을 설치했는데 숫자가 그대로면 프리미어를 완전히 껐다가 다시 켜 주세요.
- 버튼을 눌렀을 때 예상하지 못한 오류가 나면 패널 맨 위 빨간 상자에 오류 문구가 그대로 나옵니다. 그 문구를 알려 주면 원인을 바로 찾을 수 있어요.

### 자가 진단

시퀀스를 열어 두고 **설정 → 자가 진단 시작**을 누르면, 이 프리미어에서 플러그인 기능이 되는지 한 번에 점검합니다: 시퀀스 읽기, 재생헤드 이동, 프레임 내보내기, 그래픽 텍스트 읽기(글자를 어디서 읽었는지와 그래픽 클립의 효과·속성 구조까지), 마커 만들기·지우기, 구독 연결 프로그램(또는 API 키). 테스트 마커는 바로 지우고 Claude 사용량은 쓰지 않아요. 결과 글을 복사하거나 **진단 결과 저장**으로 저장해서 Claude에게 보내 주면 문제를 바로 찾을 수 있어요.

## 알아 둘 점

- Claude는 **정지 화면만** 봅니다. 소리, 움직임, 프레임과 프레임 사이 내용은 볼 수 없어요. 간격을 좁히면 더 꼼꼼해지지만 비용이 늘어납니다.
- 프리미어 API로는 캡션 트랙의 글자를 바로 읽을 수 없어서 SRT로 내보낸 뒤 불러옵니다. 캡션이 컨펌용 프레임 이미지에 찍혀 나오는지는 프리미어 버전에 따라 다를 수 있어요.
- **타임라인 그래픽 텍스트 읽기**는 프리미어 버전에 따라 글자 값을 못 받을 수 있어서 레이어·클립 이름과 화면 받아 적기로 보완합니다. 화면 받아 적기는 그래픽 클립 하나에 프레임 한 장을 Claude에게 보내요 (구독 방식은 사용량에서 차감, API 방식은 클립 100개에 대략 0.3~0.6달러).
- 구독 연결 프로그램은 PC 환경 변수에 `ANTHROPIC_API_KEY`가 있어도 빼고 Claude Code를 실행해서, 항상 로그인한 구독으로 돌아갑니다.
- 구독 방식은 지금 Windows만 됩니다. Mac에서는 API 방식을 쓰세요.
- 구독 방식은 구독 요금제의 사용 한도 안에서 돌아갑니다. Opus로 프레임을 많이 보내면 한도에 빨리 닿을 수 있어요.
- API 방식 대략의 비용: Claude Opus 5.5로 프레임 40장 컨펌 한 번에 0.3~0.6달러, 자막 300줄 맞춤법 검사에 0.05~0.2달러. Sonnet 5.5는 절반, Haiku 5.5는 훨씬 저렴합니다 (설정 탭에서 모델 변경).
- API 방식에서 Claude가 안전 정책 때문에 요청을 거절하면, Anthropic 서버가 권장 대체 모델로 자동으로 다시 시도하도록 켜 두었습니다 (Opus·Sonnet).
- 보내는 데이터: 컨펌 때는 프레임 이미지·요청사항·(선택 시) 자막 목록이 Claude로 (구독 방식은 PC의 Claude Code를 거쳐서), 맞춤법 검사 때는 자막 글자만 갑니다. 네이버 엔진을 고르면 자막 글자가 네이버로 갑니다.
- 프리미어 버전에 따라 동작이 다를 수 있어요. 오류 메시지가 나오면 그대로 알려 주세요.

```
premiere-plugin/
  plugin/              ← 프리미어에 설치되는 플러그인 (manifest.json, index.html, main.js)
    lib/claude.js      맞춤법·컨펌 프롬프트와 응답 형식, API 방식 호출
    lib/bridge.js      구독 방식: 구독 연결 프로그램과 주고받기
    lib/premiere.js    프리미어 UXP API (프레임 내보내기, 마커, 재생헤드, 그래픽 텍스트)
    lib/textvalue.js   그래픽 글자 꺼내기 (속성 값, 레이어 이름, 클립 이름)
    lib/ocr.js         화면 받아 적기: 장면 고르기, 겹친 그래픽 글자를 클립별로 나누기
    lib/naver.js       네이버 맞춤법 검사기 (루트의 spellcheck.py를 옮긴 것)
    lib/srt.js         SRT·VTT·TXT 읽기/쓰기 (루트의 srt_io.py와 같은 규칙)
    lib/…              비교, 프레임 시점, 리포트, 저장소
  bridge/claude-bridge.ps1  구독 연결 프로그램 (PowerShell, 127.0.0.1:41234~41237 → claude -p)
  tests/               Node 테스트 (가짜 프리미어로 패널 전체를 눌러 보는 테스트 포함)
  build_ccx.py         plugin/ → dist/*.ccx, 윈도우 설치 묶음 zip
```

- 테스트: `cd premiere-plugin && npm install && npm test`
- 설치 파일 다시 만들기: `python3 build_ccx.py`
- 프리미어 UXP API 타입: [`@adobe/premierepro`](https://www.npmjs.com/package/@adobe/premierepro), 예제: [AdobeDocs/uxp-premiere-pro-samples](https://github.com/AdobeDocs/uxp-premiere-pro-samples)
