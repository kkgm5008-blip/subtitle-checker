# 인터뷰 편집 팀 파이프라인 (Claude Code)

내 PC의 Claude Code에서 `/interview-edit` 한 번으로 인터뷰 영상을
**분석 → 대표 승인 → 편집 → 자막 → 검수** 순서로 진행하는 팀입니다.

## 파일 목록

| 파일 | 설치 위치 | 역할 |
| --- | --- | --- |
| `agents/analyst.md` | `~/.claude/agents/` | 분석팀: 핵심 주제 3줄, 이야기 단위별 남김/삭제/확인 필요, 흐름 확인, 남긴 구간의 무음·더듬기 → `01_분석안.md` |
| `agents/editor.md` | `~/.claude/agents/` | 편집팀: 분석안 구간만 50개씩 타임라인 뒤쪽부터 리플 삭제 → `02_편집보고.md` |
| `agents/captioner.md` | `~/.claude/agents/` | 자막팀: SRT 맞춤법·줄바꿈(한 줄 15~18자), 타이밍 유지, 캡션 트랙으로 넣기 → `03_자막보고.md` |
| `agents/reviewer.md` | `~/.claude/agents/` | 검수팀: 핵심 주제·흐름·남은 무음·빈 공간·자막 겹침·맞춤법 확인 → `04_검수보고.md` |
| `commands/interview-edit.md` | `~/.claude/commands/` | 진행 명령 `/interview-edit` |
| `install.ps1` | (설치용) | 위 파일을 내 PC의 `~/.claude`로 복사 |

## 준비물

1. **Claude Code** (내 PC에 설치·로그인)
2. **프리미어 프로 MCP**: Claude Code가 프리미어의 시퀀스를 읽고 자를 수 있게 해 주는 연결 도구입니다.
   어도비 공식 제품은 없고 커뮤니티에서 만든 것들이 있습니다. 설치한 도구가
   시퀀스·클립 읽기, 편집점 추가(레이저), 리플 삭제, SRT 캡션 가져오기를 지원하는지 확인하세요.
   이 도구가 없으면 분석팀이 "프리미어 연결 도구 없음"으로 멈춥니다.
3. **ffmpeg**: PowerShell에서 `winget install Gyan.FFmpeg` (무음 측정용)

## 설치 (윈도우)

1. 이 폴더를 통째로 내려받습니다.
2. `install.ps1`을 마우스 오른쪽 버튼 → **PowerShell에서 실행**
   (윈도우 11은 **추가 옵션 표시**를 누르면 보입니다)
3. 같은 이름의 파일이 이미 있으면 `.bak`으로 백업한 뒤 덮어씁니다.

직접 복사해도 됩니다: `agents` 안의 4개 → `C:\Users\내이름\.claude\agents\`,
`commands\interview-edit.md` → `C:\Users\내이름\.claude\commands\`

## 사용법

1. 프리미어에서 인터뷰 시퀀스를 열어 둡니다(활성 시퀀스).
2. 편집 전 시퀀스로 자동 캡션을 만들고 SRT로 내보냅니다.
   창 > 텍스트 → 스크립트 탭 → 시퀀스 트랜스크립션(한국어) → 캡션 만들기 → 캡션 탭 `···` → SRT 파일로 내보내기
3. Claude Code를 열고 입력합니다.

   ```
   /interview-edit 신제품 소개, 3분 내외
   ```

4. 진행 순서
   1. 바탕화면\편집작업\날짜_시간 폴더가 생기고, 영상 목적과 원본 SRT 경로를 물어봅니다.
   2. 분석팀이 `01_분석안.md`를 쓰면 요약(핵심 주제, 원래→예상 길이, 삭제 표, 확인 필요)을 보여 주고 **대표 승인**을 기다립니다. 확인 필요 항목 중 지울 번호를 말하거나, 고쳐서 다시 분석하게 할 수 있습니다.
   3. 승인하면 편집팀이 시퀀스를 백업(`…_편집전_백업`)한 뒤 자릅니다.
   4. 편집된 시퀀스로 자동 캡션을 **다시** 만들어 SRT 경로를 알려 달라고 합니다.
   5. 자막팀이 고친 `자막_교정.srt`를 캡션 트랙으로 넣습니다.
   6. 검수팀이 확인하고, 문제가 있으면 담당 팀에 한 번만 돌려보낸 뒤 재검수합니다.
   7. 마지막에 전체 결과를 짧게 보고합니다.

## 알아 둘 점

- 문장 중간의 더듬기는 SRT만으로 정확한 위치를 알 수 없어 자동으로 자르지 않고 '확인 필요'로 표시합니다.
- 말소리 트랙 말고 B-roll·음악이 있는 트랙도 리플 삭제로 같이 잘립니다. 분석안의 주의점을 꼭 보세요.
- 잠긴 트랙이 있으면 편집팀이 멈춥니다(싱크가 깨지지 않도록).
- 자막이 들어간 뒤 추가로 자르면 자막도 같이 잘리므로, 그 경우 진행자가 대표 승인을 다시 받습니다.
