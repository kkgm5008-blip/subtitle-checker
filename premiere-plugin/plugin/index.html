Claude 사용 방식
내 Claude 구독으로 쓰기
이 PC에 설치한 Claude Code가 Claude 구독(Pro·Max)으로 검사합니다. 구독 사용량에서 차감되고 따로 돈이 들지 않아요. 처음 한 번만 준비하면 됩니다.
1. PowerShell에서 irm https://claude.ai/install.ps1 | iex 로 Claude Code를 설치하고, claude 를 한 번 실행해 내 Claude 계정으로 로그인합니다.
2. 설치 묶음(zip)에 들어 있는 claude-bridge.ps1을 마우스 오른쪽 버튼으로 눌러 PowerShell에서 실행. 프리미어를 쓰는 동안 그 창을 켜 둡니다.
3. 아래 구독 연결 확인.

구독 방식: Opus는 사용량을 많이 써요. 구독 한도에 자주 걸리면 Sonnet으로 바꾸세요. Pro 요금제에서 Opus가 안 되면 Sonnet을 고르세요.
API 방식 대략의 비용: Opus 5.5로 프레임 40장 컨펌 한 번에 0.3~0.6달러, 자막 300줄 맞춤법 검사에 0.05~0.2달러. Sonnet 5.5는 절반입니다.
자가 진단
이 프리미어에서 플러그인 기능이 동작하는지 한 번에 점검합니다. 시퀀스를 열어 두고 누르세요. 테스트 마커를 잠깐 만들었다 지우고, Claude 사용량은 쓰지 않아요.
위 글을 복사해서 Claude에게 보내 주면 문제를 바로 찾을 수 있어요.
보내는 내용
컨펌을 누르면 뽑은 프레임 이미지, 요청사항, (선택 시) 자막 목록이 Claude로 전송됩니다 (구독 방식은 PC의 Claude Code를 거쳐서). 맞춤법 검사는 자막 글자만 보냅니다. 네이버 엔진을 고르면 자막 글자가 네이버로 갑니다.
